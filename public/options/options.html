プレースホルダ・記法の説明(クリックで展開)
記号意味例
$creatorクリエイター名sample_creator
$creatorIdクリエイター ID1234
$postTitle投稿タイトルサンプル投稿
$postId投稿 ID1234567
$date{書式}投稿日を書式で展開$date{YYYYMMDD} → 20260115
$today{書式}実行日を書式で展開$today{YYYY-MM-DD} → 2026-07-19 (実行日)
$contentId投稿内のメディアブロック通し番号42
$contentTypephoto / file / video のいずれかphoto
$plan投稿の必要支援額(feeRequired)0 / 500
$filenameファイル名(拡張子除く)。photo は UUID basename、file/video は投稿者が upload した元名image / video_a
$ext拡張子(ドットなし)png / mp4
$seqブロック内の連番(2 件以上ある時のみ、単一なら空)2
$seq{N}N 桁ゼロ詰めの連番$seq{3} → 002
$totalブロック内の総ファイル数4

$contentTitle は Fanbox には存在しないため常に空文字列になります。[...] に入れると丸ごと消えます。

/ で階層(サブフォルダ):テンプレ内の / は保存先のサブフォルダ区切りとして扱われます。例:

  • fanbox/$creatorId/$postTitle.png → fanbox/1234/サンプル投稿.png(3 階層のフォルダに保存)
  • 階層は何段でも OK、各階層のセグメントは自動 sanitize(Windows 禁止文字 / \ : * ? " < > | は置換文字に、末尾ドット/空白は除去、予約名 CON 等は回避)

日付書式:$date{} / $today{} の中に書くトークン。それ以外の文字はリテラルとして残ります。

  • YYYY 4 桁年 / YY 2 桁年
  • MM ゼロ詰め 2 桁月 / M ゼロ詰めなし月
  • DD ゼロ詰め 2 桁日 / D ゼロ詰めなし日
  • HH 時 / mm 分 / ss 秒
  • 例:$date{YYYY-MM-DD_HHmm} → 2026-01-15_1230

オプショナルグループ [ ... ]:内側にプレースホルダを 1 つ以上含む場合、そのいずれかが空文字に解決したら [...] ごと消える。単一 photo で $seq が空になった時に連番プレフィックスも一緒に消したい、みたいなユースケース用。

  • 例:[$seq{3}_]$filename.$ext
    • 複数(seq=2)→ 002_aaa.png
    • 単一(seq=空)→ aaa.png(_ も含めて消える)
  • ネスト可:x[a[$seq]_b]y の内側が空なら外側も丸ごと消える

例テンプレ(既定値):

  • 単体:fanbox/$creatorId/$date{YYYYMMDD}_$postTitle/[$seq{3}_]$filename.$ext
  • zip ファイル:fanbox/$creatorId/$date{YYYYMMDD}_$postTitle/images_$contentId.zip
  • zip 内エントリ:[$seq{3}_]$filename.$ext

zip は再開不可の一括処理で、DL 履歴にも残りません。大きい投稿や確実性が要る場合は通常ダウンロード推奨(zip にできない場合は自動で個別ダウンロードに切り替わります)。

⚠ 保存ダイアログが出る場合は Chrome 設定「ダウンロード前に各ファイルの保存場所を確認する」を OFF にしてください。拡張からは強制できません。
